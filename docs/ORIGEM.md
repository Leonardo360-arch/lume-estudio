# Origem do Lume Estúdio

Evolução autorizada do projeto acadêmico [Portf-lio-PI-2026](https://github.com/Leonardo360-arch/Portf-lio-PI-2026), referência inicial `a106e9eace4f62d87db8f6df9757c1e5f1959c4b`.

O projeto mantém PHP e MySQL e passa a usar identidade fictícia, correções de segurança e álbuns privados para entrega temporária de fotografias. Os créditos da equipe original serão preservados na documentação.
