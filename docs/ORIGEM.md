# Origem

Evolução autorizada de [Portf-lio-PI-2026](https://github.com/Leonardo360-arch/Portf-lio-PI-2026), referência a106e9eace4f62d87db8f6df9757c1e5f1959c4b.

O original permanece intacto e conserva seu histórico. O novo repositório recebe o snapshot revisado do código; o histórico Git completo não foi importado, pois o acesso disponível ao novo repositório permite a gravação pela integração, mas não autentica o push Git direto. Fotografias, dumps antigos, cópias executáveis duplicadas e PDFs do projeto anterior não integram a aplicação fictícia nova.

Créditos acadêmicos: Michael Pierre Nintz de Freitas, Leonardo Marson Coral, Denis Diego Brandão da Cunha, Eduardo Ferreira Lopes e Gabriel Neves.
