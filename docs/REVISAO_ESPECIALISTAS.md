# Revisão por especialidade

Frentes de análise e implementação assistidas por IA; créditos da equipe acadêmica original preservados no README.

| Especialidade | Sugestão | Entrega |
|---|---|---|
| Engenharia | Critérios de aceite e integração antes de ampliar escopo | Regras, integração, documentação e testes HTTP |
| Arquitetura | Manter stack, retirar DDL de requisições | Migrações, instalação CLI e contratos injetáveis |
| Cibersegurança | Proteger sessões, ações e arquivos | CSRF, rotação, reset atômico e isolamento entre contas |
| UX | Conectar descoberta, solicitação e entrega | Home, rótulos, estados vazios, prazo e progresso real |
| Backend sênior | Corrigir homônimos e concorrência | Identidade por e-mail/ID, locks e duração contratada |
| Frontend sênior | Imagens leves e CSS público separado | Identidade fictícia, WebP e galeria responsiva |
