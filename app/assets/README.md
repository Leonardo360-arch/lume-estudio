# Assets fictícios — Lume Estúdio

Estas quatro fotografias e a logomarca foram geradas com a ferramenta integrada ImageGen para uma demonstração fictícia. As pessoas e o ambiente retratados são sintéticos; não são trabalhos, clientes ou instalações reais de um estúdio. Não atribuir os retratos a pessoas reais.

As fotografias foram convertidas para WebP com Sharp, qualidade 80, largura máxima de 1600 px na capa e 1200 px nas demais. A marca conserva transparência real em PNG, 320 × 320 px. Os originais gerados foram preservados fora do repositório; a aplicação utiliza as versões otimizadas abaixo. Nenhuma fotografia original do projeto anterior foi sobrescrita.
